# 도시판 밀도 필드 × 쓰레기: 근거와 최소 코어 (2026-10-05)

땅을 도시로 바꾼 뒤, 도시 식생·토양·물 흐름을 "밀도"로 쓸 수 있는지 조사한 기록입니다.

## 한 줄 결론
- 도시 거리 쓰레기와 도시 식생의 정량 관계를 직접 다룬 연구는 찾지 못했습니다.
- 근거가 있는 것은 (1) 수변·맹그로브 식생이 쓰레기를 포집한다, (2) 강우 규모가 클수록 도시 하천의 쓰레기 유출이 는다, (3) 답압(밟기)이 식생 피복을 줄이는 곡선, 이 세 가지입니다.
- 쓰레기가 도시 식물·토양에 주는 영향은 담배꽁초와 미세플라스틱의 실험 수준 증거뿐입니다.

**근거가 없는 곳**: 거리 쓰레기 ↔ 녹지·수관, 가로수 건강, 거리 빗물받이의 막힘 정량, 강우 임계값(4.3 mm/h 같은 수치는 출처 미확정이라 쓰지 않음).

개념 틀(해석): Gandy *Concrete and Clay* · Swyngedouw & Heynen 2003 · Tsing 2015(폐허 속 생태) · Clément *제3풍경* · Kowarik 2011(신생 도시 생태계). 사실이 아니라 해석으로 표기.

## 후보 파라미터 (셀당 0..1)
**계수와 곱셈 구조는 모두 작가가 정하는 값이고 문헌 값이 아닙니다.** 문헌이 지지하는 것은 방향(부호)과 답압 곡선의 모양입니다.

| 기호 | 파라미터 | 왜 "밀도"인가 | 근거 | 0이 되면 |
|---|---|---|---|---|
| **G** | 지표 식생 피복 | 피복도는 식생 밀도의 표준 척도 | 답압 손실 강함, 쓰레기 영향 약함 | 맨땅(밟힌 길) |
| **P** | 토양 개방도 (1 푸석함, 0 압밀) | 토양 밀도(bulk density)의 역수 | 답압 → 압밀 강함(요약), 미세플라스틱 영향 중간 | 굳은 지표, 물이 고임 |
| **D** | 배수구 개방도 (1 열림, 0 막힘) | 통수 단면 점유율 (인프라 상태) | 막힘 증거 중간(하천 랙) | 침수 이벤트 |
| W | 지표 물 (파생, 저장 안 함) | 순간량이라 오버레이로 | 물리 | 웅덩이 |
| B | 잡초 피복 | 피복 | 약함 (개념 틀뿐) | 보류 |
| Bio | 생물 다양성 지수 | 파생 지수 | 약함 | 보류 |

## 최소 코어: G, P, D (+ 파생 W)
F = 보행·체류량, L = 품목 가중 쓰레기, R = 비의 세기.

```
dG/dt =  r_G·P·(K_G − G)        # 회복 (토양이 열려 있을수록 빠름)
       − a_F·F·G                # 답압: 지수 감쇠 (초반 급감, 이후 완만)
       − a_L·L_tox·G            # 쓰레기: 소폭 (꽁초 실험 방향)

dP/dt =  r_P·G·(1 − P)          # 뿌리가 천천히 토양을 엶 (해석)
       − a_P·F·P·(1 + c·Wet)    # 보행 압밀 (젖으면 더 심함, 해석)
       − a_PL·L_mp·P            # 미세 조각: 소폭

I_cap = I0·P·(1 + γ·G)          # 침투 용량
Q     = max(0, R − I_cap)       # 유출 (W의 시각화)

L_loose = L·(1 − τ·G)           # 식생이 있으면 쓰레기를 붙잡음 (수변 증거, 도시 거리는 해석)
ΔL_move = κ·Q·L_loose           # 비의 크기에 비례해 쓰레기가 배수구 쪽으로 이동
dD/dt   = −c_D·ΔL_in            # 유입된 쓰레기가 막음
D ≤ 0   → 침수 이벤트 (잉여 물이 번지고 쓰레기가 퍼짐)
회복 속도 순위: r_P ≪ r_G ≪ r_D
```

**되먹임**: 밟으면 G와 P가 줄고 → 침투가 줄고 유출이 늘고 → 쓰레기가 멀리 가고 → 배수구가 막히고 → 침수. 식생이 줄수록 쓰레기를 붙잡는 힘도 줄어듭니다. P가 0이면 G가 되살아나지 못합니다.

**외부 데이터**: 위 모델은 걷기·쓰레기 상태와 R(t)만으로 돌아갑니다. R(t)는 내부 난수로 둘 수도 있고, 원하면 강수 피드 하나만 연결하면 됩니다.

## 공백
1. 거리 쓰레기 ↔ 녹지·수관의 직접 연구 없음. 수변 증거를 도시 거리로 옮긴 것은 해석.
2. 거대쓰레기가 식물을 덮는 효과, 가로수 건강 영향은 못 찾음. G에 대한 쓰레기 항은 약하게 두는 게 정직함.
3. 거리 빗물받이 막힘의 정량 증거 없음. D의 계수는 연출 값.
4. 강우 임계값과 초기 세척: Schwenk 2025는 규모와의 양의 관계만 확인. 열대 호주는 반례.
5. 답압 곡선 형태는 비도시(산악·숲) 데이터이고 수치는 요약 수준.
6. 압밀 임계값(1.5~1.6 g/cm³) 출처 미특정. 0..1 정규화는 작가 스케일.
7. 초록만 읽은 항목이 많아서, 전시 텍스트에 수치를 인용하기 전에 본문 확인이 필요.
