### 공간 치수 (샷 값의 근거)
- 한 단 = 20 s = 월드 1 단위(`unit` 1). 현재는 **분당 3 단위**씩 올라감 → 1시간이면 180 단위.
- 융합 덩어리·레진·화석 띠는 **현재에서 45–54단 아래**부터(융합 세션 10/30). 그 아래의 구운(baked) 층은 에포크가 바뀔 때까지 계속 쌓여 기둥의 "진짜 바닥"은 하루 내내 멀어진다 → "화석 전체뷰"는 **현재를 기준으로 몇 단 아래까지**를 보는 샷으로 정의해야 안정적(절대 바닥 기준이면 오후엔 모든 게 점이 됨).
- 바닥(세로) 화각 40°. 거리 d에서 프레임 반높이 ≈ 0.364·d. 높이 각 θ로 기울여 보면 세로로 보이는 시간축 길이 ≈ 0.728·d / sin θ.
  예) 기본(75, 58°): 약 64 단위 → 초점 −25 기준 +7 … −57: 현재가 위 가장자리, 화석 띠(−45…−54)가 아래 가장자리 — 10/30에 맞춘 그대로.
- 월드는 160칸 × 1.2 = 192 단위 정사각형(토러스). 사람들이 쓰는 땅은 수십 단위. 바닥 쪽 화면 비율은 16:9 가정(가로로 1.78배 더 보임).
- 카메라 near 0.1 / far 800 — 거리 200까지는 여유.

## 3. 전환

### 3.1 무엇을 어떻게 보간하나
- 구면 좌표별로 따로: **거리는 로그 보간**(30 ↔ 140을 선형으로 하면 멀 때 빠르고 가까울 때 느려 보임), 높이 각·초점 높이·바라보는 자리·자전 배율은 선형.
- easing은 5차(6k⁵ − 15k⁴ + 10k³): 양 끝에서 속도뿐 아니라 가속도도 0 → 카메라가 "출발·도착"하는 느낌이 없음.
- target.y를 움직이는 것은 지금처럼 `SpaceWorld`의 따라가기(초점 높이만 매 프레임 공유 ref로 받음, §5). 따라가기의 완만한 추종(시간상수 ≈ 0.7 s)이 전환 12 s 위에 조금 더 얹히는 정도.

### 3.2 방향(azimuth): 샷마다 두지 않고, 자전을 계속
- 샷마다 방향을 고정하면 전환 때마다 큰 호(최단 경로를 골라도 최대 180°)를 그리며 돌아야 하고, 자전과 충돌함.
- 대신 **자전은 하나의 연속 함수**: 방향(t) = 시작 방향 + 도는 방향 · 360° · (∫배율 dt) / camTurnSec. 배율이 샷마다 다르고(위에서 0.5 등) 전환 중에도 보간되므로 적분은 구간별 닫힌식 — 주기 경계에서도 끊기지 않게 "지난 주기 수 × 한 주기의 적분값"을 더함.
- 작가가 꼭 "이 샷은 늘 이쪽에서"를 원하면: 샷에 `방향 오프셋`(자전에 더하는 각, 최단 경로로 보간)을 2단계 이후 추가 가능. 1단계엔 넣지 않음.

### 3.3 높이 각 0° 근처(바로 위)
- OrbitControls는 phi를 [ε, π−ε]로 자르고, 카메라의 up이 (0,1,0)이라 0°에선 방향이 정의되지 않음(짐벌). `StageCamera`가 이미 0.5°로 자름.
- 위에서 보는 샷은 **12°** 제안: 거의 수직인데 살짝 기울어져 자전이 "제자리 뒹굴기"가 아니라 "지도가 도는 궤도"로 읽힘. 작가가 더 수직을 원하면 5°까지(그 밑은 어지러움). 샷 사이에 0°를 지나는 일은 없음(모든 샷이 0° 위).
- V2는 90° 초과(밑에서 올려보기)가 가능하지만 90° 지날 때 지평선이 뒤집히므로, 90° 양쪽에 걸친 두 샷을 이어 두지 않도록 미리보기에서 확인.

### 3.4 따라가기(camFollow)와의 관계
- 샷은 초점 기준이므로 따라가는 대상이 바뀌어도(자동 → 최신) **구도는 그대로**, 초점만 지금처럼 옮겨 감(40 단위 넘으면 점프 — 기존 동작, 바꾸지 않음).
- 깊이 조건(§1): 샷으로 들어가는 전환이 **시작될 때** 한 번 "초점 + 초점 높이 ≥ 0"인지 보고, 아니면 그 차례의 목표를 기본 구도로 바꿈(머무는 동안 고정). 깊이는 단조 증가라 하루에 한 번만 뒤집힘.
- 따라가기는 y만 옮기고 x·z는 안 옮김 — 사람이 바라보는 자리에서 멀면 화면 밖일 수 있음(지금도 같음). 후속 선택지: "현재 가까이 샷은 따라가는 사람의 x·z를 본다"(토러스 최단 이미지로).

### 3.5 자전·해도 같은 시계로 (제안)
- 지금은 `dt` 누적이라 새로고침마다 처음부터. 자동 샷이 시계 기준이면 자전도 시계 기준이어야 "샷 ↔ 방향" 조합이 결정적임.
- 비용: GPU가 2 s 멎으면 시계 기준 방향은 4°(180 s/바퀴) 앞서 있음. 그래서 매 프레임 **목표 포즈로 완만히 다가가는 상한**(시간상수 ≈ 1.5 s)을 둠 — 멎은 뒤에도 뛰지 않고 1–2 s에 따라붙음. 마운트 때는 바로 목표 포즈에서 시작(벽이 켜지는 순간 점프 없음).
- "현재 시점 가져오기" 버튼은 지금 보는 방향에서 시계 방향을 뺀 **오프셋**을 `camAzimuth`에 쓰도록 바꿈(라벨 "시작 방향" → "방향 오프셋"). 해의 `sunTurnMin`·`sunSwing`도 같은 방식(3줄).
- 리허설 벽에서 드래그: 드래그 중엔 운행이 멈추고, 놓으면 **1–2 s에 운행 중인 포즈로 돌아감**(지금은 놓은 자리에서 계속 돎). 그 구도를 남기려면 "현재 시점을 이 샷에" 버튼(§4). 작가가 "놓은 자리에서 계속"을 더 좋아하면 자전만 `dt` 누적으로 되돌릴 수 있음(한 분기).

```
    샷 5 (꺼짐)

  해 (자동 운행)                                                  ← 그대로(시계 기준으로만 바뀜)
```

- 상태 줄(리허설 벽 왼쪽 아래 readout, ui=0에선 글자 없음 규칙대로 안 그림): `샷 기본 (41 s) → 1 화석 전체뷰` / `미리보기 샷 2` / `드래그 → 복귀`.
- 켜진 샷이 하나도 없으면 기본 구도만(자동 운행을 켜도 지금과 같음).
- 폴더 이름의 "화석 전체뷰" 같은 별명은 라벨일 뿐(키는 번호). 작가가 샷을 바꿔 쓰면 라벨은 "샷 1"로 중립화해도 됨 — 결정 요청.

### 상태 보관
- Leva 값 → `useEffect`로 `seqRef`(Sequence)에 한 번 옮겨 둠. **프레임마다 Leva를 읽지 않음**(Leva 읽기는 React 렌더).
- 프레임 상태는 ref 셋: `cur`(지금 포즈), `preview`(붙잡은 샷 번호 | null), `dragging`, `depthLatch`(이번 차례의 깊이 조건 결과). 모두 숫자/불린.
- `link = { lift, focusY }` 하나를 ParliamentSpace가 만들어 SpaceWorld와 StageCamera에 같은 ref로 줌.

### 프레임당 비용
- 지금 자전: 삼각함수 2개 + 곱셈 몇 개. 바뀐 뒤: `Date.now()` 1회, 나머지 연산 1회, 구간 찾기(샷 ≤ 6개 선형 탐색), easing 1회, 보간 6개, 삼각함수 4개. **할당 0**(out 객체 재사용), 수 µs 미만. 픽셀 바운드인 벽의 fps에 영향 없음 — 전/후 fps를 내장 브라우저에서 같은 창 크기로 측정해 기록(소리 끔 `?sound=0`, 끝나면 탭 닫기).
- 새 샷은 **그릴 것의 양**을 바꿈: 화석 전체뷰(거리 140)는 식생 점·청크가 더 많이 프레임에 들어오고, 위에서 보기는 LOD 근/중 거리를 지나감. 1단계에서 샷별 fps를 측정해 기록하고, 어떤 샷이 벽에서 무거우면 그 샷의 값(거리)이나 LOD를 조정.

### 리허설 ↔ 전시
- 같은 페이지·같은 저장 키라 리허설 벽에서 save → 서버 → 전시 벽(새로고침 또는 다음 시작)이 받음. 전시 벽은 Leva가 숨겨져 미리보기·드래그가 없으므로 운행만 함.
- `/v2/global/lab`: `active={!lab}`이라 자동 운행도 꺼짐(지금 자전과 같음).

## 6. 열린 결정 (작가)
1. 샷 기본값(§1 표) — 그대로 시작하고 리허설에서 맞출지, 처음부터 바꿀 값이 있는지(특히 위에서 보기의 12°, 화석 전체뷰의 140).
2. 샷 4·5 자리: 비워 둘지, "옆에서"나 "밑에서 올려보기"를 기본으로 넣을지.
3. 드래그 뒤 복귀(§3.5): 놓으면 운행 포즈로 돌아감 vs 놓은 자리에서 계속.
4. 전환 12 s · 주기 ≈ 5분이 전시 리듬에 맞는지(더 느리게 — 전환 20 s, 머무는 2–3분 — 도 가능).
5. 이벤트 끼어들기(도착 → 현재 가까이)는 4단계 선택지로 두는 데 동의하는지.
