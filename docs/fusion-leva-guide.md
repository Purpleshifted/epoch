# 융합 비주얼 Leva 안내 (2026-11-15)

벽(`/v2/global/space`) Leva의 `엉김 · 융합 · 레진` 폴더. 부재 하나가 덩어리가 되기까지 거치는 순서대로 ① … ⑦이 놓여 있다.

## 먼저: 융합이 읽는 숫자는 하나

부재마다 **진행**(0 = 방금 지음 … 1 = 끝)이 있다. 침식과 융합이 같은 숫자를 읽는다.

- 진행이 얼마나 빨리 가는지는 융합 폴더가 아니라 **`침식`** 폴더가 정한다: `진행에 걸리는 시간`, `놓인 뒤 아무 일 없는 시간`, `시작 깊이`, `다 깎이는 깊이`.
- 침식: `진행 × 다 깎였을 때 사라지는 몫`이 부재의 문턱을 넘으면 부재가 사라진다.
- 융합: 진행이 ①의 두 값 사이를 지나며 덩어리가 찬다.

## 폴더 맨 위

| 손잡이 | 하는 일 |
|---|---|
| 켜기 | 융합 전체 |
| 덩어리가 바뀔 때 녹아드는 시간 | 새로 계산된 덩어리로 넘어갈 때의 교차 전환(초) |

## ① 언제 덩어리가 되나

| 손잡이 | 하는 일 |
|---|---|
| 층수를 곱함 | 꼭대기에서 이 단수 아래까지는 진행이 덜 가게 함. 최신 층이 화석이 되지 않게 하는 값 |
| 자리마다 · 부재마다 다르게 | 0이면 같은 단이 한꺼번에 바뀌어 잘려 보임. 올릴수록 들쭉날쭉 |
| 덩어리가 부재를 삼키는 정도 | 0 = 부재는 그대로 보이고 덩어리가 엉겨 붙음, 1 = 부재가 녹아 사라짐 |
| 깎여 사라진 부재가 남기는 덩어리 | 0 = 깎이면 덩어리도 없음, 1 = 깎여도 덩어리는 남음. **덩어리가 듬성하면 이것부터 올린다** |
| 덩어리가 생기기 시작하는 진행 | 낮출수록 일찍 생김 |
| 덩어리가 다 차는 진행 | 위 값에 가까울수록 한꺼번에 차오름. 1 = 끝까지 천천히 |
| 뼈대까지 삼켜지는 진행 | ②의 뼈대가 덩어리에 덮이는 시점 |

## ② 얼마나 뭉치나

| 손잡이 | 하는 일 |
|---|---|
| 이어 붙는 세기 | 클수록 부재 사이가 메워져 한 덩어리. 1 = 부재 모양 거의 그대로 |
| 메워지는 틈의 너비 | 얼마나 먼 부재끼리 이어지나(복셀) |
| 고급 › 아래로 흘러내림 | 덩어리가 처지는 정도 |
| 고급 › 젊은 층 가장자리 부스러짐 | 덜 진행된 곳의 가장자리가 거칠어짐 |
| 고급 › 뼈대로 남는 부재 비율 | 날카로운 직교 형태로 남는 부재의 몫 |
| 고급 › 가시 | 표면에서 뻗는 가는 돌기 |
| 고급 › 계산 › 격자 간격 | 작을수록 세밀하고 **가장 무겁다**(반으로 줄이면 8배) |
| 고급 › 계산 › 덩어리로 치는 밀도 기준 | 낮출수록 두껍고 멀리 이어짐 |
| 고급 › 계산 › 표면 다듬기 횟수 | 0 = 각진 격자 그대로 |
| 고급 › 계산 › 식생 퇴적물이 섞이는 양 | 식생이 모인 자리에 덩어리가 더 붙음 |

## ③ 부재가 녹는 꼴

| 손잡이 | 하는 일 |
|---|---|
| 부재가 녹는 꼴 | 통째로(상자) / 관(모서리만) / 크기에 따라(작은 건 통째, 큰 건 관) |
| 관 굵기 · 관 비율 | 관으로 녹는 부재의 굵기와 몫 |
| 판은 판으로 | 슬래브 · 기단은 판 모양을 유지 |
| 배관 · 다리 · 철골도 녹음 | 건물 밖의 것들이 덩어리에 들어가는지 |
| 크기 띠 | 무엇을 "작은 부재 / 큰 부재"로 치는지. ③⑤⑥의 "작은 · 큰" 값이 모두 이 기준을 쓴다 |
| 판 사이 채우기 | 슬래브 사이의 방을 덩어리로 채움. 켜면 모든 판이 계산에 들어가 무거워진다 |

## ④ 건축 → 화석

진행이 얕은 곳은 건축(각진 형태), 깊은 곳은 화석(둥글고 속이 파임).

| 손잡이 | 하는 일 |
|---|---|
| 화석이 되기 시작하는 / 다 되는 나이 | 이 두 값 사이에서 각진 것이 둥글어짐 |
| 젊은 층의 블로키 | 덜 진행된 곳을 복셀 계단으로 남김 |
| 방 → 공동 | 오래된 곳의 방이 둥근 빈 공간이 됨 |
| 관 뼈대가 오래된 층에서 묻힘 | ③의 관이 끝에 덩어리에 묻히는 정도 |
| 겉면은 건물 윤곽대로 | 0 = 부재 밖으로 부풂, 1 = 건물 윤곽에서 잘라냄 |
| 화석화 경계의 흔들림 | 0이면 평평한 띠로 바뀜 |

## ⑤ 구멍

덩어리의 속을 비우고(껍질) 구멍을 연다. **부스러기가 생기던 곳이 여기다.**

| 손잡이 | 하는 일 |
|---|---|
| 껍질 | 속을 비우고 표면에 구멍을 엶 |
| 거품 | 속을 비우지 않고 부피째 구멍을 냄 |
| 구멍 모양 | 보로노이(다각형, 사이에 리브) / 노이즈(벌레 먹은 듯) / 둥근 구멍 / 크기에 따라 |
| 구멍 크기 | 셀 하나의 크기(월드) |
| 리브 굵기 | 구멍 사이 벽. 격자 1.5칸보다 얇아지지 않음 |
| 열리는 비율 | 구멍이 되는 셀의 몫. 진행이 깊을수록 더 열림. 높으면 리브만 남음 |
| 보로노이 비율 · 작은 / 큰 부재 | 0 = 노이즈, 1 = 보로노이 |
| 고급 › 껍질 두께 | 얕은 층 / 깊은 층의 껍질 두께 |

부스러기에 대해: `열리는 비율`이 높으면(전시 값 0.84) 남은 덩어리가 서로 떨어진 섬이 되었다. 지금은 ① 리브가 격자보다 얇아지지 않고 ② 노이즈 구멍은 0.55까지만 열리고 ③ 그래도 떨어져 나온 작은 조각(구멍 크기의 1/5보다 작은 것)은 지운다. 구멍을 줄이고 싶으면 `열리는 비율`을 내린다.

## ⑥ 곰보

표면의 작은 자국. 모양을 바꾸지 않고 음영으로 그린다(가볍다).

| 손잡이 | 하는 일 |
|---|---|
| 그늘 | 곰보 속의 어둠. 0 = 곰보 끔 |
| 양 · 크기 · 파임 | 얼마나 많이, 얼마나 크게, 얼마나 깊게 보이나 |
| 양 배율 · 작은 / 큰 부재 | 부재 크기에 따른 양 |
| 넓은 면에 몰림 · 고급 › 몰림 | 고르게 / 어떤 면에만 |
