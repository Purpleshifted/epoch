# 실시간·참여형 오픈 데이터 조사 (2026-10-05)

작품을 현실 세계와 매핑하기 위한 후보 데이터를 조사한 기록입니다.
기준: 한 건이 무엇인지 · 분류 방식 · 가져오는 방법 · 갱신 속도 · 라이선스 · 우리 모델에 연결할 곳.

### 발견
- **EMODnet 해변 쓰레기는 JRC 표의 "계속 갱신되는 판"에 해당합니다.** JRC는 이런 조사를 모아 만든 것이고, EMODnet은 같은 계열의 조사 개수를 키 없이 ERDDAP으로 줍니다. 품목 코드 체계도 이어집니다(OSPAR·TSG-ML·JLIST). 지금처럼 PDF에서 뽑는 대신 품목별 `abundance` 합계를 질의로 받을 수 있습니다. 갱신은 연 1회 수준입니다.
- **라이브는 OpenLitterMap뿐입니다.** 확인한 범위에서 즉시 갱신되는 공개 API는 이것 하나입니다.
- 재질이 직접 들어 있는 곳: EEA MLW(재질 9종), Debris Tracker(재질 대분류), MDMAP. OpenLitterMap은 재질이 선택 입력이라 비는 경우가 많습니다(샘플 2건이 비어 있었음).
- 조사형(MLW·EMODnet·MDMAP·Plastic Pirates)은 "조사 구간 합계"라서 한 점 = 한 아이템 모델과 단위가 다릅니다. 빈도 가중치로 쓰는 편이 자연스럽습니다.
- 모든 후보가 특정 국가에 몰려 있습니다(OLM: NL·UK·US, MLW 사본: CH·IT·ES). "세계의 쓰레기"가 아니라 "참여자가 많은 곳의 쓰레기"입니다.

| Seagrass-Watch · SeagrassNet · Reef Check · CoralWatch | 현장 조사 | 자체 | 연 단위 [요약] | 공개 API 미확인 | [요약] |

- OBIS에 **SeagrassSpotter.org Global Seagrass Point Dataset**(시민이 앱으로 해초를 신고)이 들어 있습니다. 거머리말 질의 1,705건 중 포함 [직접].
- GBIF `occurrenceStatus=ABSENT`가 있습니다. Zosteraceae(좌표 있는 346,157건) 중 203,883건(59%)입니다. "없음"을 알려주는 유일한 신호입니다.
- 정량 값(`organismQuantity`)은 Zosteraceae 12.9%, Ulva 13.5%뿐이고 단위가 제각각입니다(% cover, 점수, 건중량 등).
- GBIF에는 해양 필터가 없습니다. `isMarine=true`는 오류 없이 무시됩니다. 분류군 키 목록으로 걸러야 하고, "Ulva"는 사초과 속과 이름이 같은 함정이 있습니다(해조 Ulva는 `taxonKey` 9408069).
- 좌초·녹조의 오픈 라이브 시민 데이터는 찾지 못했습니다.
- **관찰 건수는 밀도가 아닙니다.** 관찰자 수가 곧 건수입니다. 이벤트 신호(방금 누가 봤다)로는 쓸 수 있지만 밀도값으로 쓰면 안 됩니다.

## 5. 키 없이, 장애에도 버티는 구조 (에이전트 제안 중 채택할 만한 것)
- 수집기가 소스들을 받아 정규화한 정적 `state.json` 하나를 만들고, 브라우저는 그 파일만 읽는다. 키·CORS·호출 한도가 브라우저에서 사라지고, 소스 장애가 격리된다.
- 소스가 끊기면 마지막 정상값을 나이와 함께 서서히 흐리게 쓰고, 그다음은 번들된 녹화본이나 계절 평균값으로 내려간다.
- 라이브 값은 필드의 목표 평균만 움직이고 노이즈는 로컬 시드로 둔다. 오프라인에서도 모양이 깨지지 않는다.
- 출처 표기 화면을 상시 둔다 (Open-Meteo는 비상업 조건, OLM은 ODbL, EMODnet은 인용 문구 의무).
