# 도시 초목(vegetation) 밀도장 리서치 — 요약본

> 상태: 서브에이전트 보고서의 핵심만 정리. **수치는 전부 [S]/[U]** (에이전트가 논문 본문을 열지 못했고 Crossref로 서지만 확인). 인용 전에 원문 확인 필요.
> 현재 구현(`apps/web/src/lib/parliament/nature.ts`)은 이 법칙을 쓰지 않는다. 임의 수식이며, 나중에 `grassDensity`만 교체하면 된다.

## 1. 유형 (0..1 cover/density로 다룰 수 있는 것)
잔디(mown lawn) · 틈새/폐허 잡초(ruderal) · 공터 초지 · 관목 · 가로수/수관 · 이끼 · 낙엽층. (녹색지붕은 제외)

## 2. 범위
| 항목 | 값 | 출처 |
|---|---|---|
| 미국 도시 수관 | 35.1 %, 불투수 17.5 % (저밀도 교외 포함) | Nowak & Greenfield 2012, doi:10.1016/j.landurbplan.2012.04.005 [V*서지, 값 S] |
| 서울 수관/녹지 | ~27 % / ~31 % | 신뢰도 낮음 [S] |
| 서울 유출률 | 10.6 % → 51.9 % (1962→2010), 불투수율 아님 | [S] |

## 3. 인간 영향
- 답압: Cole 1995 (doi:10.2307/2404429, 2404430) — 비선형, 약 75회 통과 이하에서 급감 후 포화. 생장형별 저항 차이(총생 graminoid 강, 관목/chamaephyte 약). 회복: ~25회는 1년, ≥75회는 3년 후에도 불완전 [S].
- 방목 기능형: 문헌 못 찾음. Holling II(`g_max·sheep·G/(G+K)`)는 설계 선택.
- 종자 산포는 fat-tailed (Nathan et al. 2002, doi:10.1038/nature00844).

## 4. 시간 규모 비율 (R:G:S:T ≈ 1:3:20:200) — 설계 선택 [U]

## 5. 권장 필드 세트 (모든 계수 작가 선택 [U])
| 필드 | 의미 | 초기값 도심/주거/공원/공터 |
|---|---|---|
| G 잔디 | 0..1 | 0.05 / 0.35 / 0.70 / 0.15 |
| R 잡초 | 가장 빠름, 틈에서 생존 | 0.05 / 0.05 / 0.03 / 0.40 |
| S 관목 | 답압 ×3 | 0.03 / 0.10 / 0.15 / 0.20 |
| T 수관 | overlay, 나무 역할이 제어 | 0.10 / 0.25 / 0.40 / 0.10 |
| C 콘크리트 | 불투수 | 0.85 / 0.40 / 0.10 / 0.20 |

제약 G+R ≤ 1−C. 답압 `F = F0·exp(−a_F·N)`.

## 6. 개념 참고 (해석)

## 7. 공백
도시별 실측 계수 없음. 방목 반응식 없음. 서울 수치 신뢰도 낮음.
