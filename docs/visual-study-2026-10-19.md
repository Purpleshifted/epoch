# 비주얼 스터디 (2026-10-19) — 9579: 건축물이자 뼈대 · 화석 · 서식지의 흔적

작가가 2026-10-19 밤에 정한 방향: 융합 덩어리가 "서로 떨어진 감자덩어리"가 아니라 **건축물이자 뼈대, 화석, 서식지의 흔적**으로 읽혀야 한다. 재질은 "거의 불투명한 서리 유리가 부재와 이어지는 느낌"이지 굴절이라는 광학 효과가 아니다. 그리고 **IMG_9579**를 인상적으로 본다. 이 문서는 9579를 중심으로, 지금 파이프라인(복셀 장 → surface nets → 다듬기)이 거기에 닿을 수 있는지와 무엇을 더해야 하는지를 정리한다. 레퍼런스 전반의 문법은 `reference-study-2026-10-10.md`.

## 1. 9579에 무엇이 있나

흰 무광 한 덩어리(클레이 + AO 렌더). **왼쪽·위는 복셀 건축**: 계단식 테라스, 쌓인 입방체, 작은 큐브 격자, 캔틸레버, 발코니 — 단위 큐브로 지은 거대구조이되 층·내민보 같은 건축의 리듬이 있다. **오른쪽·아래는 같은 몸체가 매끈한 뼈**: 큰 구형 공동들이 거품처럼 맞닿아 있고 그 사이엔 얇은 막, 막이 터진 자리의 구멍, 공동 안에 더 작은 공동(스케일 위계), 공동을 가로지르는 가는 실. 가운데는 **큐브가 매끈한 형태 속으로 빨려 들어가듯** 서서히 바뀐다 — 복셀 계단이 둥근 불룩함으로 흘러든다.

읽히는 것 세 가지:
1. **건축과 유기체가 한 재질 · 한 몸체**다. 유기적인 부분은 복셀 도시를 "녹인" 것이고(복셀 장을 다듬어 뽑은 면), 건축적인 부분은 같은 장을 **다듬지 않고** 뽑은 것이다. 즉 차이는 재료가 아니라 **처리**(블로키 ↔ 스무스)이고, 그 처리가 자리마다 다르다.
2. **방이 공동이 된다.** 오른쪽의 거품은 무작위 구가 아니라 건물의 방(층 사이 빈 공간)이 둥글어진 것처럼 보인다. 슬래브·벽은 공동 사이의 **얇은 막**이 되고, 얇은 곳은 터져 구멍이 난다 — 해면뼈(trabecular bone)와 같다. **서식지의 흔적 = 방의 빈 틀**: 사라진 것(사람이 쓰던 공간)이 빈 공동으로 남는다 (인계 문서에 "주형 → 빈 틀" 제안으로 있던 것).
3. **재질은 무광 흰색 + AO**, 굴절·투명·광택 없음. 형태의 연속성과 빛(공동 속 그림자)이 전부다.

9585(Sui Generis 단면)는 같은 말을 더 건축적으로 한다: 직교 인간 공간(슬래브 상자)과 유기 덩어리(바위·이끼)가 **맞물려 하나의 단면**을 이루고, 덩어리는 건물 사이를 건너 잇는다. 9586은 식생이 복셀 블록을 덮는 톤.

## 2. 지금 파이프라인에 대입

| 9579의 성질 | 우리 것 | 모자란 것 → 할 것 |
|---|---|---|
| 한 몸체, 처리만 다름 | 복셀 장(0.4) → surface nets → Taubin 2회가 **전부 균일하게** 둥글림 → 감자 | **화석화 커브**(층의 나이): 젊은 층은 **블로키**(정점을 셀 중심에 두고 다듬기 가중 0 → 복셀 계단 = 건축), 오래된 층은 매끈(다듬기 가중 1). 사이는 "녹는 큐브". 셰이더에서 블로키 정점은 면 법선(미분)으로 평평하게 |
| 젊은 건축은 상자 그대로 | `max(C, gain·blur(C))`가 젊은 층도 부풀림 | 젊은 층은 `C`(부재 상자의 합) 위주, 오래될수록 `gain·blur` — 같은 커브 |
| 방이 공동이 된다 | B 채우기는 반대(방을 메움); 둥근 공극은 무작위 구 | **방 → 공동**: B의 방 마스크를 흐려(둥글게) 오래된 층에서 **빼기**. 부재 자체(C 높은 곳)는 안 빼므로 슬래브·벽이 **막**으로 남고, 얇은 막은 터진다 |
| 거품(해면뼈) | 껍질(C)은 표면만 보로노이로 연다 | **거품**: 속을 비우지 않고 보로노이 셀을 **부피째** 공동으로(열리는 비율 = 공동이 되는 셀의 몫). 노이즈 모양이면 벌레 먹은 동굴, 둥근 모양이면 구 |
| 스케일 위계 | 크기 커브, 곰보 | 공동 크기도 부재 크기·나이에 따르게 (셀 크기 × 크기 커브) |
| 무광 흰색 + AO | 레진 = 굴절/유리 | **서리 피부**: 불투명 무광 밝은 몸체 + 피부 바로 밑 부재가 어둡게 비침(ghost) + 약한 속빛. 굴절은 선택지로만 |
| 큐브와 뼈 사이의 가는 실·다리 | 섬유 D는 뺌 | 보류 (가시·관으로 대신) |

E 관(multipipe)은 이 그림의 프레임 쪽에 해당: 젊은 층은 **관 뼈대**, 오래될수록 관 사이가 메워져 **매트릭스에 묻힌 화석**. 판(슬래브·기단)은 판으로 남고 테두리만 관, 관 굵기는 부재 크기, 관이 만나는 모서리엔 **마디**.

## 3. 결정 (이 스터디로 정한 것)

- 목표 그림: **위(현재 쪽) = 복셀 건축, 아래(과거) = 해면뼈 화석, 사이 = 녹는 큐브**. 한 메시, 한 재질(서리 피부).
- 방 → 공동이 "서식지의 흔적"의 몸. 거품은 방이 없는 덩어리(매스만 있는 건물)의 대체.
- 재질은 굴절을 버린다(선택지로만). 서리 피부 = 불투명 + ghost + 속빛 + 약한 가장자리.
- 건물 사이의 이어짐은 다리(비주얼 세션)가 들어와야 한다 — 융합 입력에 외부 부재(kind "bridge") 입구만 열어 둔다.
