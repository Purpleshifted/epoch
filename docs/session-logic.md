- 화면 전환은 **끊어서** (디지털): 어두움 ↔ 플레이 화면은 즉시 바뀜. 페이드는 죽어갈 때(LIVE → ENDED, 2초) 하나뿐. 안내 문구도 부드럽게 맥박치지 않고 켜짐/꺼짐으로 깜빡임.
- 수명은 **실제 시간**(벽시계)으로 잰다. 세계 시계(빠르게 돌릴 수 있음)와 무관.

- Leva `역할 › 세션` 끄면: 수명 없이 늘 LIVE (회사원).

### 왜 이 순서인가
비자발성(태어남) → 형식적 자발성(예만 있는 동의) → 배정받는 이름 → 묻지 않고 시작되는 삶. 2026-10-20까지는 그 사이에 선택의 환상(고르기)과 우연(슬롯)이 있었지만, 개인뷰 인터랙션을 회사원만 하기로 하면서(땅에 효과가 있는 역할도 회사원뿐) 둘 다 뺐다 — 선택지가 하나뿐인 슬롯은 농담이 아니라 지연이었다. 그 자리에 2026-11-01부터 헤드셋 안내와 이름이 온다: 멜로디가 곧 이름임을 처음 들려 주는 자리. 틀은 삶의 **앞과 뒤**에 둔다 (`docs/direction-2026-10-10.md` §1; 삶 중의 로그가 결과를 말하는 변경은 §4·2단계에서).

### 폰에서
- 폰(거친 포인터만 있는 기기, `isCoarsePointer`)에서는 키·마우스·포인터 락 대신: **손가락이 화면에 닿아 있는 동안 걷고, 떼면 머문다** (머묾/걷기가 손가락 하나에 실림); 누른 채 **좌우로 끌면 그만큼 회전**(약 300px에 반 바퀴), **위아래로 끌면 카메라 피치**(300px이 전체 범위). 그만 살기는 **상단의 버튼** — 가능한 동안(30초 이후~죽기 15초 전) 계속 보이고, 1초 길게 누르면 시도(어둠·소리·팝업·기록은 X와 같음). 탭이 SPACE·아무 키를 대신함. 문구도 폰용(`script.ts`의 `…Touch`): 삶의 처음 10초에 `누르는 동안 걷고, 떼면 머뭅니다 · 끌면 돕니다`를 아래쪽에 흐리게.
- 기울임(가속도계) 걷기는 Leva `폰 조작 › 기울임`으로만 (기본 꺼짐; 켜면 iOS가 첫 탭에서 센서 허락을 묻고 https에서만 동작). 기본에서 빠진 이유: 손은 가만히 있지 못해 **머묾**이 안 됨.
- 폰 테스트는 배포 주소(https)에서. iOS에서 길게 누를 때 텍스트 선택·메뉴·돋보기가 뜨지 않게 캔버스의 touchstart를 막고(포인터 이벤트는 그대로라 탭 진행은 됨) user-select / touch-callout을 끔.
- **페이지 잠금** (`usePageLock`, V2 플레이어 화면 동안): 텍스트 선택(시작돼도 바로 지움)·메뉴·드래그·더블탭/핀치 줌·스크롤·튕김 막음, 뷰포트는 확대 불가(`app/mobile/layout.tsx`, `app/v2/mobile/layout.tsx`). 페이지가 막을 수 없는 것: iOS 화면 가장자리 스와이프(뒤로), 홈 인디케이터, 제어 센터 → **홈 화면에 추가**해서 열면 브라우저 틀 없이 실행(뒤로 스와이프 없음), 전시장에선 **사용법 유도(Guided Access)**.
- 2026-10-20부터 관객은 언제나 회사원: `?role=`, `DRAW_DEFAULT`, Leva `배정`은 없어졌다 (되돌릴 것도 없음).

## 2. 역할 (2026-10-20부터 배정 없음)

- 관객은 내부적으로 **언제나 회사원 규칙**(`worker`)을 따른다. 고르기(CHOOSE)·슬롯(DRAW)·판정(VERDICT) 화면과 `assignRole`·`planReel`·`verdictOf`·`?role=`·`DRAW_DEFAULT`·Leva `배정`은 없앴다 (git 역사 2026-10-17~19에 남음). **화면에서는 '회사원'이라 부르지 않는다**(2026-11-01): 이름은 멜로디의 표기(§4)이고, 기록표에서는 `개체 0417`(id에서 나온 네 자리, `glyph.ts individualNo`)이다.
- 땅에 효과가 있는 역할은 회사원뿐. 봇 역할에 `섞어서`: 봇 i가 worker → cat → car → tree 차례로 — cat/car/tree는 존재 기록만 남기고 건물·길에는 안 들어간다.

## 3. 수명이 다해갈 때 (마지막 `warnSec`)

경고 세기 `warn` = 0 → 1, 제곱으로 (처음엔 살짝, 끝으로 갈수록 급하게).

| | warn = 0 | warn = 1 |
|---|---|---|
| 커서(점) 깜빡임 | 1.2 Hz, 켜짐 60 % | 10.8 Hz, 켜짐 35 % |
| 소리: 저역통과 | 그대로 | 열린 땅 → 220 Hz, 건물 위 → 150 Hz (로그 보간, warn^0.7) |
| 소리: 음량 | 그대로 | 전체 × 0.5, 다른 사람 × 0.4, 식생 노이즈 × 0.3 |
| 조작: 속도 | × 1 | × 0.4 |
| 조작: 반응 (drag) | × 1 | × 0.2 (느리게 따라옴, 미끄러짐) |
| 조작: 시점 감도 | × 1 | × 0.4 |
| 조작: 끊김 | 없음 | 입력이 덩어리로 끊김 (값 노이즈, 끝에서 약 절반) |

ENDED: 소리 0, 입력 무시, 포인터 락 해제.

## 4. 기록 (witness + ledger) — 사는 동안은 쉬운 말로

2026-10-20까지는 "사실만, 결과는 절대 말하지 않는다"(영어 대문자 기계 로그)였다. 작가가 그 원칙을 거뒀다: **개인뷰도 삶이 땅에 한 일을 말한다**. 2026-11-01 작가가 목소리를 둘로 나눴다: **경험하는 동안은 유기적으로, 알아듣기 쉽게 흘려 주고, 마지막 표(§11)만 표본을 보듯 말한다.** 글로벌 뷰는 여전히 같은 사건을 시간의 크기로 보여 준다.

- 기록은 **구조화된 항목** `LogEntry {t, key, args, level}` (`witness.ts`). 문구는 `script.ts`의 `LOG[lang]`이 만든다. 쉬운 문장, 숫자는 꼭 필요할 때만, 퍼센트와 몫은 없다. `?lang=`/Leva 언어를 따른다. 접두 `T+mm:ss`는 늘 기계 서체.
- **이름 = 멜로디의 표기** (`glyph.ts`): id마다 이미 있는 모티프(`lib/sound/motif.ts`)를 가로 8칸(마디의 스텝) × 세로 8칸(음 높이)에 적는다(`Glyph`). 음 하나는 다음 음까지의 길이만큼의 막대. 높은 목소리는 칸 위쪽에 앉는다. 읽기만 한다: 소리는 바꾸지 않는다. 기록 칸 맨 위에 `이름:`과 내 표기, 맨 아래에 지금 곁에 있는 이들의 표기.
- **중요도** `level`: 0 사실(회색) · 1 눈에 띄는 것(흰색) · 2 중요(흰 바탕에 검은 글자).
- 사실 줄(witness): 곁 = 생성 규칙의 존재 반경(`radius`, 기본 3); 떠남은 × 1.3 바깥이고 1.5초 유지돼야 기록(시각 폭 때문에 표본이 경계를 오가는 봇의 도배를 막음); 상태 변화도 1.5초 유지돼야 기록; 땅 풀밭 / 다져진 길(길 ≥ 0.3) / 콘크리트 위(슬래브 ≥ 0.15). 상태 줄 `머무는 중 00:12 · 풀밭 · 곁에 2명`, 함께 지을 때 `합주 중 00:12 · …`. 줄은 5개 유지. 남이 걷기 시작하거나 멈췄다는 줄은 없앴다(소음). `observe()`는 시야 24 안의 모두(`far`)도 내놓는다.
- 합계 (`summary()`): 머문 초, 곁에 있던 초, 만난 수 + 역할별 만난 수, 마지막 지면, 군집(`group`: 5초 이상 곁에 있던 이), 새 어휘(`newWords`), 발견한 말(`found`), 합주한 초(`ensembleSec`) → 기록표와 사인(§9)의 재료.
- **결과 줄 = 장부(ledger, §11)의 사건.** 조건이 1.5초 유지돼야 쓰고(접기 꼬리의 잠정값 방지), 8초에 하나씩, 중요한 것부터(콘크리트 > 길 > 봉인 아래 > 풀 눌림 > 풀 회복 > 혼자 > 앞선 길 > 다짐); 30초 넘게 기다린 줄은 버린다.

## 9. 사인 (cause of death) — `intake.ts` `causeOfDeath(role, record, u)`

세션 기록이 사인을 정한다 (관객이 실제로 한 일). 위에서부터 첫 일치, 동률은 세션마다 한 번 뽑은 `u`. 비율은 수명 대비 (머묾 = stillSec/lifeSec, 가까이 = nearSec/lifeSec). 관객은 회사원이므로 쓰이는 건 회사원 행뿐; 나머지 행은 봇 역할과 작가의 표로 남겨 둔다.

| 역할 | 규칙 |
|---|---|
| 모든 역할 | 그만 살기 성공(`endedBy = self`) → 자살 |
| 회사원 | 머묾 ≥ 0.6 & 가까이 ≥ 0.4 & 봉인 지면 → 과로 · 만남 0 → 고독사 · 머묾 ≤ 0.3 & 다져진 땅 → 교통사고 · 기본 → 병사 / 심정지 |
| 길고양이 | 다져진 땅 & 자동차 만남 ≥ 1 → 로드킬 · 만남 0 & 머묾 ≤ 0.3 → 아사 · 열린 땅 & 머묾 ≥ 0.6 → 저체온 · 회사원 만남 ≥ 3 → 포획 · 기본 → 병사 |
| 자동차 | 머묾 ≤ 0.3 & 가까이 ≥ 0.4 → 추돌 · 머묾 ≥ 0.6 & 만남 0 → 방치 · 봉인 & 회사원 만남 ≥ 1 → 압류 · 기본 → 폐차 |
| 나무 | 회사원 만남 ≥ 3 또는 봉인 → 벌목 · 다져진 땅 → 도로 확장 · 열린 땅 & 만남 0 → 낙뢰 · 기본 → 고사 / 병충해 |

- 퇴장 화면 `생존`은 수명(lifespan)이면 `lifeSec`, 그만 살기면 실제 산 시간.
- **그만 살기 (회사원만)**: LIVE 30초 뒤부터, **죽기 15초 전까지** 가능 (`stopAllowed`; 마지막 15초엔 띠도 키도 없음 — 끝이 오는 중에 실패하면 되살아나는 듯 보였음). 안내는 화면 상단에 선명한 띠로 `그만 살기: X 키를 1초 동안 누르세요` — 30초마다 5초씩 간간이 (`hintUp`; **띠가 있든 없든, 실패 팝업이 떠 있든 말든 키는 먹힘**). 시간은 모두 Leva. 키는 **X** (LIVE 중엔 포인터 락이라 화면 버튼은 못 누름 — `STOP_KEYS`). 1초(Leva) 누르고 있는 동안 어둠이 0 → 0.9로 차오르고(`lifeRef.attempt`), 소리는 끝처럼 닫히고(`muffleSound`), 조작은 죽는다. 중간에 놓으면 아무 일도 없음(어둠 하드 컷). **소리만은 릴리즈 엔벨롭**(2026-10-28, 작가: 실패 뒤 갑자기 되돌아오는 소리가 튀었다): `lifeRef.attemptSound`가 홀드를 따라 오르되 놓거나 실패하면 e-folding 0.7 s로 풀린다 — `muffleSound`는 이 값을 쓴다. 시간이 차면 `attemptEnd(u, p)`, p = `selfChance(성공 확률, 가까운 존재 수)` = Leva `성공 확률 (혼자일 때)`(기본 0.35 — 실패 문구가 더 세므로 실패가 흔한 쪽) × `가까운 존재 1명당 ×`(기본 0.5)^n — **혼자일수록 성공, 봇이든 사람이든 곁에 있으면 줄어듦** (n = 그 순간 기록의 NEAR 반경 안의 수; 기록 줄에 `· NEAR n`으로 남음). 실패: 어둠 하드 컷 0, 중앙에 상자형 팝업으로 4초 `저런. 그만 살기에 실패했습니다. 삶은 계속됩니다.`; 바로 다시 시도 가능(쿨다운 없음, 팝업 중에도), 수명은 계속. 기록 스트림에 `YOU  TRIED TO STOP LIVING` / `YOU  FAILED` 두 줄, 퇴장 화면에 `그만 살기  n회 시도 · 실패`. 성공: 죽음 페이드 2초 → ENDED, `endedBy = self`, 사인 자살, 생존 = 실제 산 시간. 고양이·차·나무에게는 이 선택지가 없다.
- **D LLM 다양화 (예정, 선택)**: 수명의 끝 시각을 미리 알므로 마지막 `warnSec` 동안 `POST /api/cause`에 기록을 보내 미리 생성 → 지연 없음. 8초 타임아웃·오프라인·오류 → 표로 폴백. 서버 env `ANTHROPIC_API_KEY` + `CAUSE_LLM=1`일 때만. 출력은 "사인 2~6자 + 한 문장"으로 제한.

## 10. 전시 운영 — 아이맥 두 화면, 배포

- 모바일 ↔ 글로벌 동기화는 **localStorage만** (`lib/parliament/log.ts`, `useWorld.ts`): 같은 브라우저 프로필, **같은 origin**(프로덕션 도메인 — `www` 유무·`http/https`가 다르면 다른 저장소, Vercel 프리뷰 URL은 배포마다 달라 쓰지 말 것), 탭이 아닌 **창 두 개**(각 화면에 전체화면). 이 조건이면 웹에 배포해도 그대로 동작. 네트워크가 끊겨도 이미 로드된 두 창은 계속 돈다 (새로고침만 못 함).
- 다른 컴퓨터에서 벽을 띄우려면 서버 저장소가 필요 (Vercel KV + `/api/events` 폴링) — 보험으로만 적어 둠.
- 전시 URL 예: 아이맥 `/v2/mobile?ui=0&lang=ko`, 벽 `/v2/global/space?ui=0`.
- 벽에는 캡션·문구를 두지 않는다 (2026-10-17 결정): 벽은 말 그대로 훔쳐보는 창이고, 그 구성은 작가가 따로 한다.
