# 세션 · 역할 · 수명 (V2 개인 뷰)

살아있는 규칙 문서. 바뀌면 같은 커밋에서 고친다. 코드: `lib/parliament/session.ts` (슬롯·수명 규칙), `lib/parliament/intake.ts` (삶의 앞뒤: 안내 단계, 판정, 사인), `lib/parliament/script.ts` (문구, 한/영), `lib/parliament/witness.ts` (건조한 기록), `components/parliament/useLifeSession.ts` (상태 기계), `components/parliament/SessionHud.tsx` (화면). V2 전용 — V1은 예전 그대로 (Leva에서 역할 고르기, 수명 없음).

- 화면 전환은 **끊어서** (디지털): 어두움 ↔ 플레이 화면은 즉시 바뀜. 페이드는 죽어갈 때(LIVE → ENDED, 2초) 하나뿐. 안내 문구도 부드럽게 맥박치지 않고 켜짐/꺼짐으로 깜빡임.
- 수명은 **실제 시간**(벽시계)으로 잰다. 세계 시계(빠르게 돌릴 수 있음)와 무관.
- 300ms 안의 두 제스처는 하나로 (탭 = pointerdown + touchend; 누르고 있는 키의 반복은 무시). Leva 패널·입력창 위의 제스처는 세션으로 치지 않는다.
- Leva `역할 › 세션` 끄면: 수명 없이 늘 LIVE, 역할은 `배정`에서 고른 것 (랜덤이면 worker).

### 왜 이 순서인가
비자발성(태어남) → 형식적 자발성(예만 있는 동의) → 선택의 환상(고르기) → 우연(슬롯). 삶의 조건이 하나씩 쌓이고, 고른 직후 "반영되지 않았습니다"가 핵심. 역할이 **선택지가 있는지 자체**를 정한다(§9 그만 살기는 회사원만). 퇴장 화면의 `(요청: 나무)`가 마지막 건조한 농담. LIVE 중에는 지금처럼 와닿지 않게 두고, 틀은 삶의 **앞과 뒤**에만 둔다 (`docs/direction-2026-10-10.md` §1).

## 2. 역할 배정

- 후보: `worker` · `cat` (STREET CAT) · `car` · `tree` — 균등 랜덤 (`assignRole`). Leva `배정`으로 하나를 고정할 수 있음.
- **관객이 CHOOSE에서 고른 역할은 배정에 쓰이지 않는다.** `wanted`로만 남아 VERDICT와 퇴장 화면에 적힌다. 판정 `verdictOf(wanted, drawn)`: 같으면 `lucky`(1/4), 다르면 `unlucky`.
- 슬롯: 네 역할이 고정된 순서로 도는 릴. 처음엔 빠르고(약 25장/초) ease-out으로 느려져 뽑힌 역할에서 멈춘 뒤 세 번 깜빡이고 고정 (`planReel`, `reelAt`). 결과는 돌기 전에 이미 정해져 있다 (연출만 슬롯). 릴의 글자는 언어와 무관하게 영어 대문자 (`ROLE_TAG`) — 선택 버튼 아래에 같은 영어 꼬리표를 작게 보여 짝을 익히게 한다.
- **아직 worker만 땅에 효과가 있다.** cat/car/tree로 배정되면 존재 기록만 남고 건물·길에는 안 들어감.
- 봇 역할에 `섞어서`: 봇 i가 worker → cat → car → tree 차례로.

## 3. 수명이 다해갈 때 (마지막 `warnSec`)

경고 세기 `warn` = 0 → 1, 제곱으로 (처음엔 살짝, 끝으로 갈수록 급하게).

| | warn = 0 | warn = 1 |
|---|---|---|
| 커서(점) 깜빡임 | 1.2 Hz, 켜짐 60 % | 10.8 Hz, 켜짐 35 % |
| 소리: 저역통과 | 그대로 | 열린 땅 → 220 Hz, 건물 위 → 150 Hz (로그 보간, warn^0.7) |
| 소리: 음량 | 그대로 | 전체 × 0.5, 다른 사람 × 0.4, 식생 노이즈 × 0.3 |
| 조작: 속도 | × 1 | × 0.4 |
| 조작: 반응 (drag) | × 1 | × 0.2 (느리게 따라옴, 미끄러짐) |
| 조작: 시점 감도 | × 1 | × 0.4 |
| 조작: 끊김 | 없음 | 입력이 덩어리로 끊김 (값 노이즈, 끝에서 약 절반) |

ENDED: 소리 0, 입력 무시, 포인터 락 해제.

## 4. 건조한 기록 (witness)

목표: 개인 뷰에서는 하는 일이 **와닿지 않게** — 사실만 (거리, 지속 시간, 상태). 그 결과(머묾 = 콘크리트, 걷기 = 길)는 절대 말하지 않는다. 글로벌 뷰에서 처음 보이게. 언어 설정과 무관하게 **영어 대문자** (장치의 원출력; 장치가 관객에게 말하는 문구만 §8의 언어).

- NEAR = 생성 규칙의 존재 반경(`radius`, 기본 3)과 같은 거리. 즉 "가까이"는 건물 규칙이 세는 바로 그 범위지만, 화면은 그걸 말하지 않는다.
- 떠남은 반경 × 1.3 바깥 (경계에서 깜빡이지 않게). 상태 변화는 1.5초 유지돼야 기록.
- 줄 형식: `T+01:23  WORKER #03  NEAR · 2.1 M NE · STATIONARY`, `… GONE · NEAR FOR 00:41`, `YOU  STATIONARY`, `SURFACE  TRODDEN GROUND`.
- 상태 줄: `YOU  STATIONARY 00:12 · OPEN GROUND · NEAR 2`.
- 땅: OPEN / TRODDEN (길 형성 ≥ 0.3) / SEALED (슬래브 ≥ 0.15).
- 방위는 월드 기준 8방위 (+z = N).
- 그만 살기 실패: `T+00:41  YOU  TRIED TO STOP LIVING · NEAR 2`, `T+00:41  YOU  FAILED` (성공은 세션이 끝나므로 줄이 없음).
- 합계 (`summary()`): 머문 초, 가까이 있던 초, 만난 수 **+ 역할별 만난 수, 마지막 지면** → 퇴장 화면과 사인(§9)의 재료.

## 8. 원고 — 어조 (`script.ts`)

- 화자 = 삶을 **배정하고 기록하는 장치**. 누구의 장치인지(고고학자들의 것인지) 말하지 않음 — 시간 역설을 건드리지 않고 모호함을 유지.
- 1인칭 없음, 감탄사·느낌표 없음(테스트가 막음), 합니다체. 한 문장 20자 전후, 한 화면 ≤ 3줄.
- 가능하면 **숫자·상태**로 말한다 (`약 3분`, `요청/배정`, `생존 03:00`).
- 유머는 문장이 아니라 **배치**에서: 예만 있는 선택지, 접수됐지만 반영 안 됨, 사인 옆의 요청 역할. 농담을 설명하지 않는다.
- 작품 의미(흔적 → 해석)는 단정하지 않는다: "줄 수도, 주지 않을 수도" (concept.md의 당위성 배제).
- 두 층: 장치가 **말할 때**는 선택 언어(한/영, 한글은 픽셀 서체), 장치의 **원출력**(기록·슬롯)은 영어 대문자 VT323. 영어 안내는 문장체(대문자 아님)로 층을 구분.
- 레퍼런스: 1in8b.life (80억 분의 1) — 통계와 사실을 담담히; 여기서는 더 건조하게.

## 9. 사인 (cause of death) — `intake.ts` `causeOfDeath(role, record, u)`

세션 기록이 사인을 정한다 (관객이 실제로 한 일). 위에서부터 첫 일치, 동률은 세션마다 한 번 뽑은 `u`. 비율은 수명 대비 (머묾 = stillSec/lifeSec, 가까이 = nearSec/lifeSec).

| 역할 | 규칙 |
|---|---|
| 모든 역할 | 그만 살기 성공(`endedBy = self`) → 자살 |
| 회사원 | 머묾 ≥ 0.6 & 가까이 ≥ 0.4 & 봉인 지면 → 과로 · 만남 0 → 고독사 · 머묾 ≤ 0.3 & 다져진 땅 → 교통사고 · 기본 → 병사 / 심정지 |
| 길고양이 | 다져진 땅 & 자동차 만남 ≥ 1 → 로드킬 · 만남 0 & 머묾 ≤ 0.3 → 아사 · 열린 땅 & 머묾 ≥ 0.6 → 저체온 · 회사원 만남 ≥ 3 → 포획 · 기본 → 병사 |
| 자동차 | 머묾 ≤ 0.3 & 가까이 ≥ 0.4 → 추돌 · 머묾 ≥ 0.6 & 만남 0 → 방치 · 봉인 & 회사원 만남 ≥ 1 → 압류 · 기본 → 폐차 |
| 나무 | 회사원 만남 ≥ 3 또는 봉인 → 벌목 · 다져진 땅 → 도로 확장 · 열린 땅 & 만남 0 → 낙뢰 · 기본 → 고사 / 병충해 |

- 퇴장 화면 `생존`은 수명(lifespan)이면 `lifeSec`, 그만 살기면 실제 산 시간.
- **그만 살기 (회사원만)**: LIVE 30초 뒤부터, **죽기 15초 전까지** 가능 (`stopAllowed`; 마지막 15초엔 띠도 키도 없음 — 끝이 오는 중에 실패하면 되살아나는 듯 보였음). 안내는 화면 상단에 선명한 띠로 `그만 살기: X 키를 1초 동안 누르세요` — 30초마다 5초씩 간간이 (`hintUp`; **띠가 있든 없든, 실패 팝업이 떠 있든 말든 키는 먹힘**). 시간은 모두 Leva. 키는 **X** (LIVE 중엔 포인터 락이라 화면 버튼은 못 누름 — `STOP_KEYS`). 1초(Leva) 누르고 있는 동안 어둠이 0 → 0.9로 차오르고(`lifeRef.attempt`), 소리는 끝처럼 닫히고(`muffleSound`), 조작은 죽는다. 중간에 놓으면 아무 일도 없음(어둠 하드 컷). 시간이 차면 `attemptEnd(u, p)`, p = `selfChance(성공 확률, 가까운 존재 수)` = Leva `성공 확률 (혼자일 때)`(기본 0.35 — 실패 문구가 더 세므로 실패가 흔한 쪽) × `가까운 존재 1명당 ×`(기본 0.5)^n — **혼자일수록 성공, 봇이든 사람이든 곁에 있으면 줄어듦** (n = 그 순간 기록의 NEAR 반경 안의 수; 기록 줄에 `· NEAR n`으로 남음). 실패: 어둠 하드 컷 0, 중앙에 상자형 팝업으로 4초 `저런. 그만 살기에 실패했습니다. 삶은 계속됩니다.`; 바로 다시 시도 가능(쿨다운 없음, 팝업 중에도), 수명은 계속. 기록 스트림에 `YOU  TRIED TO STOP LIVING` / `YOU  FAILED` 두 줄, 퇴장 화면에 `그만 살기  n회 시도 · 실패`. 성공: 죽음 페이드 2초 → ENDED, `endedBy = self`, 사인 자살, 생존 = 실제 산 시간. 고양이·차·나무에게는 이 선택지가 없다.
- **D LLM 다양화 (예정, 선택)**: 수명의 끝 시각을 미리 알므로 마지막 `warnSec` 동안 `POST /api/cause`에 기록을 보내 미리 생성 → 지연 없음. 8초 타임아웃·오프라인·오류 → 표로 폴백. 서버 env `ANTHROPIC_API_KEY` + `CAUSE_LLM=1`일 때만. 출력은 "사인 2~6자 + 한 문장"으로 제한.

## 10. 전시 운영 — 아이맥 두 화면, 배포

- 모바일 ↔ 글로벌 동기화는 **localStorage만** (`lib/parliament/log.ts`, `useWorld.ts`): 같은 브라우저 프로필, **같은 origin**(프로덕션 도메인 — `www` 유무·`http/https`가 다르면 다른 저장소, Vercel 프리뷰 URL은 배포마다 달라 쓰지 말 것), 탭이 아닌 **창 두 개**(각 화면에 전체화면). 이 조건이면 웹에 배포해도 그대로 동작. 네트워크가 끊겨도 이미 로드된 두 창은 계속 돈다 (새로고침만 못 함).
- 다른 컴퓨터에서 벽을 띄우려면 서버 저장소가 필요 (Vercel KV + `/api/events` 폴링) — 보험으로만 적어 둠.
- 전시 URL 예: 아이맥 `/v2/mobile?ui=0&lang=ko`, 벽 `/v2/global/space?ui=0`.
- 벽에는 캡션·문구를 두지 않는다 (2026-10-17 결정): 벽은 말 그대로 훔쳐보는 창이고, 그 구성은 작가가 따로 한다.
