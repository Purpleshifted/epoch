# 세션 · 역할 · 수명 (V2 개인 뷰)

살아있는 규칙 문서. 바뀌면 같은 커밋에서 고친다. 코드: `lib/parliament/session.ts` (규칙), `lib/parliament/roleControls.ts` (역할별 조작), `lib/parliament/witness.ts` (건조한 기록), `components/parliament/useLifeSession.ts` (상태 기계), `components/parliament/SessionHud.tsx` (화면). V2 전용 — V1은 예전 그대로 (Leva에서 역할 고르기, 수명 없음).

## 1. 흐름

| 단계 | 언제 | 관객이 남기는 것 | 조작 · 소리 | 화면 |
|---|---|---|---|---|
| IDLE | 다음 관객을 기다림 | 없음 (봇은 계속 걸음) | 없음 · 무음 | 거의 검은 화면 (0.94), 빈 역할 슬롯, `TOUCH TO BEGIN` |
| DRAW | 첫 터치/클릭/키 (또는 퇴장 화면에서 스페이스) | 없음 | 없음 · 무음 | 거의 검은 화면, 슬롯만 보임 — 돌다가 멈춤 (~3초) |
| LIVE | 역할이 정해진 뒤 | 존재 이벤트 (역할 = 배정된 것) | 됨 (끝에서 둔해짐) · 소리 시작 | 건조한 기록 + 역할, `CLICK TO LOOK` (포인터 락은 LIVE부터) |
| ENDED | 수명이 다함 | 없음 — 땅에서 지워짐 | 없음 · 무음 | 검은 화면, 퇴장 문구와 합계 |
| → IDLE | `endHoldSec` 뒤 | | 새 관객 = 새 id, 새 시각 배정 |

- 화면 전환은 **끊어서** (디지털): 어두움 ↔ 플레이 화면은 즉시 바뀜. 페이드는 죽어갈 때(LIVE → ENDED, 2초) 하나뿐. 안내 문구도 부드럽게 맥박치지 않고 켜짐/꺼짐으로 깜빡임.
- 수명은 **실제 시간**(벽시계)으로 잰다. 세계 시계(빠르게 돌릴 수 있음)와 무관.
- Leva에서 Leva 패널을 누르는 건 세션 시작으로 치지 않는다.
- Leva `역할 › 세션` 끄면: 수명 없이 늘 LIVE, 역할은 `배정`에서 고른 것 (랜덤이면 worker).

## 2. 역할 배정

- 후보: `worker` · `cat` (STREET CAT) · `car` · `tree` — 균등 랜덤 (`assignRole`). Leva `배정`으로 하나를 고정할 수 있음.
- 슬롯: 네 역할이 고정된 순서로 도는 릴. 처음엔 빠르고(약 25장/초) ease-out으로 느려져 뽑힌 역할에서 멈춘 뒤 세 번 깜빡이고 고정 (`planReel`, `reelAt`). 결과는 돌기 전에 이미 정해져 있다 (연출만 슬롯).
- **아직 worker만 땅에 효과가 있다.** cat/car/tree로 배정되면 존재 기록만 남고 건물·길에는 안 들어감.
- 봇 역할에 `섞어서`: 봇 i가 worker → cat → car → tree 차례로. 나무 봇은 뿌리박혀 있음 (봇이 시작될 때 선 자리에 그대로).

## 2a. 역할별 조작 (`roleControls.ts`)

같은 키(WASD)와 마우스가 역할마다 다른 뜻. 간단하게 — 몸의 모델 하나씩. 끝이 다가올 때의 둔해짐(§3)은 모든 역할에 똑같이 걸림.

| 역할 | 이동 | 시선 · 눈높이 | 땅과의 관계 | HUD 안내 |
|---|---|---|---|---|
| WORKER | 걷기 (예전 그대로): 앞 7, 옆걸음 4.5, 뒤 2.8 | 마우스 그대로 · 보통 | — | `W A S D  WALK · MOUSE  LOOK` |
| STREET CAT | 짧게 내달리고 금방 섬: 앞 10, 옆 7, 뒤 3, 반응 × 2.5 | 마우스 × 1.4 · 낮고 가까이 (거리 × 0.4, 내려다보는 각 ≤ 0.5) | — | `W A S D  MOVE · MOUSE  LOOK` |
| CAR | W 가속 · S 브레이크(멈춘 뒤 후진 4) · A/D 조향 (굴러갈 때만, 반속 이상에서 1.6 rad/s). 옆걸음 없음, 옆으로 미끄러지지 않음. 느리게 붙고(× 0.22) 길게 굴러감(× 0.06), 브레이크 × 0.9 | 마우스 좌우는 안 돎, 상하만 × 0.6 · 멀고 높게 (거리 × 1.3) | 최고 속도 14 × 땅: SEALED 1 · TRODDEN 0.7 · OPEN 0.3 — 건물은 안 보이지만 속도로 느껴짐 | `W  THROTTLE · S  BRAKE · A D  STEER` |
| TREE | 뿌리박힘: 키는 줄기만 흔듦 (최대 0.35, 놓으면 돌아옴). 기록에는 늘 STATIONARY | 마우스 × 0.35 · 수명 동안 눈이 올라감 (거리 × 0.6 → × 1.8, 자람) | — | `ROOTED · MOUSE  LOOK` |

- 땅(SURFACE)은 건조한 기록과 같은 판정(OPEN / TRODDEN / SEALED)을 0.5초마다 읽는다. 세션이 꺼져 있으면 땅을 모르므로 차는 어디서나 최고 속도.
- 안내는 역할 칸 밑에 LIVE 동안 작게. 포인터 락 중 왼쪽 위 줄도 같은 문구.
- Leva `역할 › 역할별 조작` 끄면 모두 회사원처럼 걷기 (비교용). V1은 늘 회사원 조작.

## 3. 수명이 다해갈 때 (마지막 `warnSec`)

경고 세기 `warn` = 0 → 1, 제곱으로 (처음엔 살짝, 끝으로 갈수록 급하게).

| | warn = 0 | warn = 1 |
|---|---|---|
| 커서(점) 깜빡임 | 1.2 Hz, 켜짐 60 % | 10.8 Hz, 켜짐 35 % |
| 소리: 저역통과 | 그대로 | 열린 땅 → 220 Hz, 건물 위 → 150 Hz (로그 보간, warn^0.7) |
| 소리: 음량 | 그대로 | 전체 × 0.5, 다른 사람 × 0.4, 식생 노이즈 × 0.3 |
| 조작: 속도 | × 1 | × 0.4 |
| 조작: 반응 (drag) | × 1 | × 0.2 (느리게 따라옴, 미끄러짐) |
| 조작: 시점 감도 | × 1 | × 0.4 |
| 조작: 끊김 | 없음 | 입력이 덩어리로 끊김 (값 노이즈, 끝에서 약 절반) |

ENDED: 소리 0, 입력 무시, 포인터 락 해제.

## 4. 건조한 기록 (witness)

목표: 개인 뷰에서는 하는 일이 **와닿지 않게** — 사실만 (거리, 지속 시간, 상태). 그 결과(머묾 = 콘크리트, 걷기 = 길)는 절대 말하지 않는다. 글로벌 뷰에서 처음 보이게.

- NEAR = 생성 규칙의 존재 반경(`radius`, 기본 3)과 같은 거리. 즉 "가까이"는 건물 규칙이 세는 바로 그 범위지만, 화면은 그걸 말하지 않는다.
- 떠남은 반경 × 1.3 바깥 (경계에서 깜빡이지 않게). 상태 변화는 1.5초 유지돼야 기록.
- 줄 형식: `T+01:23  WORKER #03  NEAR · 2.1 M NE · STATIONARY`, `… GONE · NEAR FOR 00:41`, `YOU  STATIONARY`, `SURFACE  TRODDEN GROUND`.
- 상태 줄: `YOU  STATIONARY 00:12 · OPEN GROUND · NEAR 2`.
- 땅: OPEN / TRODDEN (길 형성 ≥ 0.3) / SEALED (슬래브 ≥ 0.15).
- 방위는 월드 기준 8방위 (+z = N).
- 퇴장 화면: `PRESENT`, `STATIONARY`, `NEAR OTHERS … · n MET`, `THE RECORD IS KEPT.`

## 6. Leva (역할 폴더)

`세션` · `배정` · `역할별 조작` 기본 켬 · `수명 (s)` 기본 180 · `끝이 느껴지는 마지막 (s)` 기본 40 · `퇴장 화면 (s)` 기본 10 · `수명 시계 배율` 기본 1 (테스트용: 수명만 빨리 흐름, 세계 시계·슬롯·퇴장 화면은 실제 시간 그대로; 기록의 T+ 시각은 수명 시계).

## 7. 열린 것

- cat / car / tree의 땅 효과 (흔적). 조작은 정해짐(§2a), 남기는 것은 아직.
- 역할마다 한 가지 행동 (스페이스)? 예: 고양이 웅크림, 자동차 경적, 나무 씨앗.
- 자동차 봇·고양이 봇의 움직임 (지금은 회사원처럼 걷고, 나무 봇만 뿌리박힘).
- 역할마다 다른 수명? (지금은 하나)
- 모바일 터치 조작 (지금 조작은 WASD + 마우스).
- 슬롯 소리 (릴 틱) — 사운드 세션과.
- 기록 문구 다듬기 (영어 / 한국어).
