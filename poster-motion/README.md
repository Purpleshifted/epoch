# 발견된 인류 — 모션 포스터 (poster-motion)

졸업심사 발표 대본(「발견된 인류 — 졸업심사 발표 구성과 대본」, Claude 문서)의 일곱 구간을 그대로 따라가는 55초 루프.
세로 1080 × 1920. A0 포스터(하늘·지표면·땅에 매달린 구조물·떠 있는 슬래시 주석·멜로디 기호)의 시각 언어를 움직이게 한 것이다.

## 보기

```
node poster-motion/tools/serve.mjs 3018      # http://localhost:3018/
```

(아무 정적 서버든 된다. `file://`로 열면 JSON fetch가 막히므로 서버를 쓴다.)

- 스페이스: 멈춤/재생 · ←/→: 1초 이동(Shift: 5초) · h: 시간 표시
- `?t=30` 그 시각부터 재생 · `?still=1&t=30` 그 시각에 멈춤

## 영상으로

```
node poster-motion/tools/render.mjs                 # out/motion-poster.mp4 (H.264, 30 fps) + out/still.png
STILLS=6,14.5,52.5 node poster-motion/tools/render.mjs   # 그 시각의 PNG만 (out/still_<t>.png)
```

헤드리스 Chrome(음소거)으로 프레임을 하나씩 찍고 ffmpeg로 묶는다. 페이지가 시간의 순수 함수(`window.__seek(t)`)라서 프레임이 정확하다.
`FPS`, `DUR`, `STILL`(스틸 시각), `CHROME`(실행 파일 경로) 환경변수로 바꾼다. `out/`은 git에 넣지 않는다.

글은 index.html의 `.tag`(슬래시 주석)와 `.cap`(구간별 캡션) 블록에 그대로 있다. 시각은 `T`, 태그의 등장 시각은 `TAG`, 캡션은 `CAP`, 기호는 `SIGN`.

## 재료

- `assets/structure.webp`: 벽 기둥 렌더 `poster-a0/renders/wide_alpha.png`(19 존재, 브랜치 `claude/a0-poster-design-89bf0a`, git 밖)를 1600 px로 줄인 것.
- `assets/plan.webp`: 같은 폴더의 `plan.png`(위에서 본 건물·배관)를 무채색 900 px로.
- `data/glyphs.json` `figure.json` `traces.json`: `poster-a0/data/`와 같은 것(작품 코드가 만든 이름 기호 400개, 이름 a·상대 b·새 어휘, 18 존재의 궤적을 3점마다 하나로 줄임).
- `fonts/`: Pretendard Bold·Regular(OFL, 한글 전체 + 라틴 서브셋 woff2), Neo둥근모(`apps/web/public/fonts/neodgm.woff2`).

## 아직 정하지 않은 것

- 날짜·장소는 넣지 않았다(미정). 하늘 오른쪽 위 `KAIST · 2026`만.
